PORT SOLARA – direkt spielbar
Starten: Diesen Ordner in VS Code öffnen -> index.html -> Rechtsklick -> "Open with Live Server". Fertig.
(Internet nötig: three.js und SoundCloud werden online geladen.)

Radio (im Auto):
 - Q wechselt den Sender (Sender 1-5 = SoundCloud, Sender 6 = Funkstille ohne Ton). Beim Wechsel erscheint ein Pop-up mit dem Sender.
 - Zu Fuß ist das Radio komplett stumm.
 - Ist bei einem Sender kein SoundCloud-Link/Haken gesetzt (oder SoundCloud startet nicht), kommt lautes Rauschen.
 - SoundCloud-Links eintragen: im Hauptmenü beim Radio/Playlist-Fenster, Speichern.
